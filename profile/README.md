## What we do

itereon GmbH is an independent software company in Vienna. We work along three lines:

- **AI strategy** – assessing where AI creates value in an organisation and what it takes to get there.
- **Intelligent automation** – turning that assessment into automated, AI-supported processes.
- **Software engineering** – building and running the production systems behind it.

Details, references and contact: **[www.itereon.eu](https://www.itereon.eu)**.
